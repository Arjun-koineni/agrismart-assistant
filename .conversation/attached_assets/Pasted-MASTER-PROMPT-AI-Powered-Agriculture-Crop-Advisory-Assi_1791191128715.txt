2. Core Mission Directive
Build a comprehensive, intelligent agricultural advisory platform that empowers farmers, agronomists, and agricultural extension officers to make data-driven crop management decisions. The application leverages Google's Gemini models (@google/genai SDK) to deliver real-time crop health diagnostics, yield predictions, fertilizer recommendations, pest/disease mitigation strategies, and localized weather-integrated advisory plans based on structured soil, climate, and crop parameters.

3. Product Goal
Provide an intuitive, lightning-fast, and deeply functional SaaS-grade web platform where users can:

Input field conditions (soil metrics, NPK values, pH, historical weather, crop type, and growth stage).

Receive structured, AI-generated multi-parameter crop advisory reports with actionable treatments, dosage calculations, and economic forecasts.

Manage farm profiles, track historical advisories, and export professional PDF/JSON agronomic reports.

Interact with an embedded conversational AI agronomist assistant for real-time troubleshooting.

4. Mandatory Features
AI Crop Diagnostics & Advisory Engine: Multi-modal or structured input analysis yielding comprehensive health scores, risk assessments, and targeted interventions using @google/genai.

Interactive Farm & Field Management Dashboard: CRUD operations for fields, real-time soil metric tracking, and historical log analysis.

Smart Fertilization & Irrigation Calculator: Automated calculation of NPK deficits, water requirements based on evapotranspiration estimates, and scheduling.

Conversational Agronomist Chatbot: Context-aware RAG-ready chat interface powered by Gemini for answering nuanced crop health questions.

Report Generation & Export: Clean, printable summary views and downloadable structured reports.

Secure Authentication & Role-Based Access: Session-based/Token-based authentication with strict Row Level Security (RLS) ensuring farmers only access their respective fields and advisories.

7. User Flow
Onboarding / Authentication: User signs up or logs in securely.

Field Setup: User registers a new field specifying location, soil type, total acreage, and current crop.

Advisory Generation: User initiates an advisory, inputs current soil test metrics (N, P, K, pH) and notes any observed symptoms or weather anomalies.

AI Processing: Backend validates input via Zod, constructs a strict prompt with JSON schema enforcement, queries Gemini via @google/genai, and validates the output.

Review & Action: User reviews the generated advisory report (fertilizer plan, pest risk, irrigation schedule), saves it to the database, and can query the AI chat for follow-up clarifications.

10. Database Schema (Production SQL for PostgreSQL)
SQL
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Users Table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Fields Table
CREATE TABLE fields (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    field_name VARCHAR(100) NOT NULL,
    location VARCHAR(255) NOT NULL,
    area_acres NUMERIC(10, 2) NOT NULL,
    soil_type VARCHAR(50) NOT NULL,
    current_crop VARCHAR(100) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Soil Metrics Table
CREATE TABLE soil_metrics (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    field_id UUID NOT NULL REFERENCES fields(id) ON DELETE CASCADE,
    nitrogen NUMERIC(8, 2) NOT NULL,
    phosphorus NUMERIC(8, 2) NOT NULL,
    potassium NUMERIC(8, 2) NOT NULL,
    ph_level NUMERIC(4, 2) NOT NULL,
    organic_carbon NUMERIC(5, 2),
    test_date DATE NOT NULL DEFAULT CURRENT_DATE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Advisories Table
CREATE TABLE advisories (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    field_id UUID NOT NULL REFERENCES fields(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    crop_stage VARCHAR(50) NOT NULL,
    health_score INTEGER CHECK (health_score BETWEEN 0 AND 100),
    summary TEXT NOT NULL,
    raw_ai_response JSONB NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Chat History Table
CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    field_id UUID REFERENCES fields(id) ON DELETE SET NULL,
    role VARCHAR(20) CHECK (role IN ('user', 'model')) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Indexes for performance
CREATE INDEX idx_fields_user_id ON fields(user_id);
CREATE INDEX idx_soil_metrics_field_id ON soil_metrics(field_id);
CREATE INDEX idx_advisories_field_id ON advisories(field_id);
CREATE INDEX idx_chat_messages_user_id ON chat_messages(user_id);
11. Row Level Security (RLS) / Data Isolation Rules
Ensure multi-tenant data security at the database and application layer:

Application Layer: All queries involving fields, advisories, and chat logs must explicitly filter by the authenticated session's user_id.

Database Layer (RLS Policies):

SQL
ALTER TABLE fields ENABLE ROW LEVEL SECURITY;
ALTER TABLE soil_metrics ENABLE ROW LEVEL SECURITY;
ALTER TABLE advisories ENABLE ROW LEVEL SECURITY;
ALTER TABLE chat_messages ENABLE ROW LEVEL SECURITY;

-- Example policy for fields (assuming current_setting('request.jwt.claim.sub', true) maps to user id or handled via app middleware)
CREATE POLICY user_isolation_fields ON fields
    FOR ALL
    USING (user_id = NULLIF(current_setting('app.current_user_id', true), '')::UUID);

const prompt = `

// Call configuration with responseSchema enforcement
const response = await ai.models.generateContent({
  model: 'gemini-2.5-flash',
